## 0. 證據（腳本輸出）

以 `MmWaveSwitchStats` 之開機 attach 建 (cell, RNTI) → IMSI（D-30 無合法 mmWave 換手），逐秒比對 `RxPacketTrace`（mmWave PHY 下行）與 RLC 報表狀態：

| | RLC：有 mmWave 報表之 UE-秒（41,523） | RLC：僅 LTE 錨點報表之 UE-秒（30,477） |
|---|---|---|
| 該秒仍有 mmWave PHY 下行傳輸之比例 | — | **1.0（8／8 seed）** |
| SINR（UE-秒平均之中位數，8 seed 範圍） | 7.7 至 10.9 dB | **−11.7 至 −3.2 dB** |
| TB 損壞比例（平均，8 seed 範圍） | 0.25–0.30 | **0.59–0.74** |
| mmWave PHY 位元組／秒（中位數，8 seed 範圍） | 440,039–848,349 | **28,929–38,779** |

**白話**：論文所稱「LTE-only」「掛到錨點」「消失」，在 D-30 中**不是** UE 離開 mmWave cell 或換手，而是 **mmWave 鏈路嚴重劣化、該秒 mmWave cell 之 DL RLC 報表沒有這個 UE、只剩 LTE 錨點報表有它**。PHY 層仍連著同一個 mmWave cell（且 `MmWaveSwitchStats` 無任何後續切換事件）。

**不宣稱**：劣化之成因（遮蔽、距離、干擾）未逐一歸因；mmWave RLC 列為何於此時缺席之內部機制未查（只陳述觀測）。

## 1. 處理原則

- **術語保留、定義改正**：「成員轉移／成員消失／LTE-only 停留」在正文出現 67 處，全面改名風險高且易漏。建議保留術語，於 3.3.3 與 4.8.1 加一段**術語界定**，並只改**明確宣稱實體移動**之句子（下表）。
- H_i 之驗證邏輯不受影響：D1 驗證的是「報表層級之歸屬序列」與凍結基線是否一致，這正是被攻陷 DU 能竄改之對象；改的是對其**物理意義**之描述。
