## 2. 等式與命題

符號：節點集合 J（mmWave cell 2–8 與 anchor 1）；U_j = 節點 j 本窗報表之 UE 集合；R = 登記名單（|R| = N = 30）；T_j = 節點 j 之真實集合。

- **E1**：|∪_j U_j| = N
- **E2**：Σ_j |U_j| = N（等價於「沒有 UE 同時出現在兩份報告」，在 E1 成立時）
- **E3**：∪_j U_j ⊆ R

**假設**：(H1) 至多一個被攻陷節點 a；(H2) 其他節點如實回報 U_j = T_j；(H3) 乾淨分割：T_j 兩兩不交、∪_j T_j = P；(H4) 母體封閉：P = R。

**命題 1**：在 H1–H4 下，E1 ∧ E2 ∧ E3 ⇔ U_a = T_a。

證明：(⇐) 顯然。(⇒) 由 H2、H3，Σ_{j≠a}|U_j| = N − |T_a|，代入 E2 得 |U_a| = |T_a|。∪_j U_j = (P∖T_a) ∪ U_a，E1 給 |(P∖T_a) ∪ U_a| = N = |P∖T_a| + |T_a|，故 |U_a ∖ (P∖T_a)| = |T_a| = |U_a|，即 U_a ∩ (P∖T_a) = ∅。由 E3 與 H4，U_a ⊆ R = P，故 U_a ⊆ T_a；又 |U_a| = |T_a|，得 U_a = T_a。∎

**系理（歸責，皆在 H1–H4 下）**：
- C3：E3 違反 ⇒ 回報未登記 ID 之節點即為 a（誠實節點不回報 R 外之 ID）。**單一節點、健全。**
- C2：UE u 同時出現在 U_j、U_k ⇒ a ∈ {j, k}（誠實集合兩兩不交）。**只能歸責到一對**；集合本身無法分辨哪一個。
- C1：只有 E1 違反（缺 UE、無重疊）⇒ a 為真實集合含缺失 UE 之節點，**報表本身無法觀測**；須外部參照（CU-CP，E25）或時間推論。

**H4 之必要性**：若 R ⊋ P，攻擊者以「已登記但未連線」之 ID 等量替換，三式皆成立（反例），故命題須明寫 H4。

## 3. 歸責政策（比較三種）

- **P-field（現行）**：任一式違反 ⇒ 全部節點 rejected。
- **P-sound（只用系理）**：E3 ⇒ 該節點 rejected；E2 ⇒ 重疊之一對皆 rejected；只有 E1 ⇒ 全部節點 abstain（不採信、不 rejected、不觸發 token 撤銷）。token 撤銷只在單一節點歸責時觸發（只 C3）。
- **P-temporal（啟發式）**：P-sound 加上時間推論——重疊之 u 歸責給「u 最近一次只被一個節點回報之窗中**不是**該節點」者；缺失之 u 歸責給上一窗回報 u 之節點。**非健全**：合法移動當窗可被誣陷（§4.3）。
