問題：單窗 S_i 看不到 0.11–0.18 之偏離；攻擊者須「同方向、持續」偏離才有效用，故多窗平均之帶符號殘差可能看得到。**先決條件**：乾淨資料之帶符號殘差多窗平均須夠接近 0（無持續性偏差）；否則誤報過高，此方向不必做。

## 2. 量測

- 帶符號殘差 r(j, w) = (tgt − ref) ÷ scale，僅於 S_i 可用之 (節點, 窗)。
- 逐 (seed, 節點)：筆數、平均、標準差、lag-1 自相關（依可用窗之順序）。逐節點跨 seed 之平均（看偏差是否固定於節點）。
- 區塊：逐 (seed, 節點) 依序取不重疊之 L 個可用窗，L ∈ {5, 10, 20, 30}；區塊統計 = r 之平均。
- 門檻 θ = ½ × 全體乾淨 (節點, 窗) 之 0.108·tgt÷scale 之中位數（即 a = 0.892 所造成位移之一半；規則事先寫定，數值由資料算出）。
- 乾淨誤報 FA(L) = \|區塊平均\| ≥ θ 之區塊比例。
- 偵測 DET(L, a) = 以 r′ 取代 r 後 \|區塊平均\| ≥ θ 之區塊比例，a ∈ {0.892, 0.822}（對應 \|a−1\| = 0.108、0.178）。**固定階躍、非適應**。

## 3. 判定（事先寫定）

- **成立**：存在 L ≤ 30 使 FA(L) ≤ 0.05 且 DET(L, 0.892) ≥ 0.80。
- **不成立**：所有 L 皆 FA(L) > 0.20 或 DET(L, 0.892) < 0.50。
- 其餘：**不確定**。
- 另報：於最佳 L 下 FA > 0.20 之 (seed, 節點) 數（異質性）。

## 4. 檢查（失敗即停）

- E23P-0：round(\|r\|, 2) 與規則版回放註記之 `z_S` 逐筆相同；筆數 = 15,534。
- E23P-1：a = 1 時 r′ ≡ r。

## 5. 限制（事先揭露）

- 「成立」只表示對**固定階躍**有訊號；E21-S4 已顯示對固定攻擊者之優勢在學習型攻擊者下可不保持。成立 ⇒ 值得寫正式規格並以學習型攻擊者驗證；不代表可採用。
- θ 以攻擊幅度定義，實際偵測器不知 a；此處僅為可行性量測。
