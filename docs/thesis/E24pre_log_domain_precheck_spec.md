**判讀（須與判定一併閱讀；判定之二分法未涵蓋最大之因素）：**
1. **最大之增益來自門檻，不是 log 域也不是全域參照**：同為線性／peer，S_i 原判定（τ_S = 4）對 ×0.8 為 0.055，改用乾淨 0.95 分位門檻（A）即為 0.629。A 之門檻換算為 z = 2.14–2.55（θ_A ÷ 凍結尺度 0.0565–0.0619 ms），**即 E21 之次門檻變體 Global(s ≈ 2.5)**——該變體已於 E21-S4 對學習型攻擊者判「不保持」（V2_s2.5：最壞誘導率 0.840／0.835、最壞 MF 0.960／0.963；E21 §8.10）。
2. log 域之額外增益（B − A）：×0.8 +0.136、×0.892 +0.094。全域參照之額外增益（D − B）：×0.8 +0.105、×0.892 +0.157。E ≈ B：差異來自比值（相對）尺度，而非「先取 log 再平均」。
3. 乾淨誤報集中於少數序列（各統計量皆 6／56 個 (seed, 節點) 之 FA > 0.20），與 E23-pre 之持續性節點偏差一致；log 域未消除之。
4. B 對學習型攻擊者之偏離量區間（×0.892）僅 0.241。E21-S4 中 V2_s2 之學習型攻擊者 MF 0.86–0.87（即偵測約 0.13，與 A 之 0.147 相符）；B 於同幅度約多 0.09，且攻擊者可再縮小偏離量。**未以學習型攻擊者驗證；依現有證據預期不足以改變 S4 之結論，但此為預期而非結果。**

**結論**：E23 之「意外觀察」主要是已知之次門檻 S_i 訊號（E21-S2／S3）換一種寫法；log／相對尺度是真實但幅度有限之改進。不更動 τ_S 與主結果。
