# B2／B3：CUSUM、ARL0、偵測時累積偏差（教授 2026-11-18 審查意見；P0）規格 v0

**接續** `B1_log_onesided_spec_v0.md`（同資料、同 LOSO、同對數殘差尺度 V2）。不改主結果與凍結值。

## 偵測器（事前固定）
- 殘差：r_t = log d_t − median(log peers)；z_t = r_t／s_log（s_log = 訓練 seed 乾淨對數殘差之 1.4826·MAD）。
- 單窗（V3、V2）：門檻依 ARL0 目標換算（單窗誤報率 p = 1／ARL0），由訓練 seed 之乾淨 z 分位數決定。
- CUSUM（Page 1954）：報低 S⁻_t = max(0, S⁻_{t−1} − z_t − k)；報高 S⁺_t = max(0, S⁺_{t−1} + z_t − k)；告警即歸零。**k = 0.5 固定**（教科書值，針對 1σ 位移；不在評估資料上挑）。h 由訓練 seed 之乾淨序列以「告警間平均窗數 = ARL0 目標」二分搜尋決定。
- ARL0 目標：100 窗與 1,000 窗（1 窗 = 1 秒）。訓練資料共約 7×7×300 窗，ARL0 = 1,000 之估計誤差大，如實報告受測 seed 之實測 ARL0。
- 雙側 CUSUM（報低＋報高各一，h 相同，合計 ARL0 目標）另列。

## 攻擊（有上限，回應 B2）
- 報低：階躍 ×{0.5, 0.6, 0.7, 0.8, 0.9}；漂移 factor = max(0.5, 1 − r·t)，r ∈ {0.005, 0.01, 0.02}。
- 報高：階躍 ×{1.2, 1.5}；漂移 factor = min(2.0, 1 + r·t)（**上限 2 倍**），r 同上。
- 注入起點 = 序列中點；偵測器從序列起點連續執行（攻擊前之誤報照算、告警後歸零）。

## 指標（B2 主指標）
- 偵測延遲（注入後第一次告警之窗數；攻擊半段無告警 = 右設限，報比例）。
- 首次告警時之累積偏差 |o/d − 1|。
- **告警前攻擊者已取得之 steering 次數**：注入後、首次告警前，攻擊者回報值低於所有 peer 回報值之窗數（代理決策：最低回報延遲）。
- 乾淨實測 ARL0（受測 seed，攻擊半段與全序列）。
- 「首次告警」受乾淨誤報污染：另報 clean 序列同區段之首次告警延遲作為基線，兩者並列，不相減宣稱。
