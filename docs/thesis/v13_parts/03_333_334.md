#### 3.3.3 (B) H_i：跨小區 UE 成員轉移一致性殘差（消失 + 瞬移）

H_i 驗證「UE 在各 cell 報表中之出現、缺席與歸屬變化是否符合封閉 NPN 的場域與架構約束」，設計上用以補 C_i 的涵蓋邊界（C_i 只驗基數守恆、不驗成員組成）。分兩個性質不同的維度：

> **術語界定**：「mmWave 缺席」「消失」「成員轉移」皆指 **E2 報表層級之觀測**。MC 架構下 PDCP SDU 以機率 `perPckToLTE` = 0.5 分流至 LTE，每個已連線之 UE 每窗本即有 LTE 路徑之 PDU；故 D1 不以「出現於 LTE」定義，而以「已連線但當窗無任何 mmWave cell 之接收」定義。此狀態與 mmWave 鏈路劣化之關係為相關、非機制證明，於 D-50PH 以 PHY 交叉驗證【待定】。

**D1 成員消失（非參數統計檢定）**

對 UE x 於窗 t，令 $d(x,t)$ 為截至 t 之**連續 mmWave 缺席窗數**：x 於該窗之報表時點在 RRC 連線名單上（3.3.1），但 $\sum_{j \ne 1} \Delta N_{\text{Rx},x,j}(t) = 0$（任何 mmWave cell 皆無接收）。停留之分布不假設任何參數形式，採不依賴分布假設的非參數方法；對每個 UE x，由乾淨資料建 Hampel identifier 與經驗分布：

```
z_d(x,t) = ( d(x,t) − median_x ) / ( 1.4826 · MAD_x )       （Hampel robust z）
p_emp(x,t) = P( 乾淨停留(x) ≥ d(x,t) )                       （經驗 p 值，非參數）
D1 strong  ⟺ z_d ≥ τ_H^reject；D1 warning ⟺ τ_H^warn ≤ z_d < τ_H^reject   （τ_H^warn = 2、τ_H^reject = 3；p_emp 僅作解釋性佐證）
```

停留分布之形狀（是否多峰、重尾）於 D-50PH 上描述【待定】。per-UE 基線的必要性：UE 可能分「常駐 mmWave」與「結構性訊號差的 edge UE」兩群，全域單一門檻會系統性誤判後者。**基線由乾淨資料之訓練 seed 估計（LOSO）、永不線上更新**——否則攻擊者可緩慢養高某 UE 停留以撐大門檻（即以自身近期觀測為參照者之同一弱點，4.7.3）。

**D2 成員瞬移（情境特定之斷言）**

> 概念先例：以移動之物理可能性（最大速度、突然出現）檢驗回報，見於 VANET 之位置驗證（Leinmüller et al., 2006；van der Heijden et al., 2018）。D2 之差異在於檢驗對象為 UE 於 cell 間之成員轉移，且由 RIC 以多節點之報告與換手事件交叉檢查，而非單一節點自報之位置。

D-50PH 開啟合法之 NR 間換手（`--handoverMode=FixedTtt`）。合法之 serving cell 改變必伴隨一筆成功之換手事件，故：

```
moved(x,t)    := (x 於 t−1 之 mmWave serving cell 為 A) ∧ (x 於 t 之 mmWave serving cell 為 B ≠ A)     （serving cell 取自 RRC 連線名單）
teleport(x,t) := moved(x,t) ∧ ¬∃ 成功換手事件 (x, A → B)，其完成時間落於 (t−1, t]（容許之時間對齊見 4.8.4）
D2 violated ⟺ ∃x: teleport(x,t)
```

此規則係由本 ns-O-RAN 場景之換手機制導出，為**情境特定之斷言（scenario-specific assertion）**，並非一般 O-RAN 部署中必然成立之架構定律。其判定不依賴可調門檻。與前版之差異：前版資料無合法換手，乾淨基線為 vacuous；D-50PH 含合法換手，乾淨資料上之誤觸數為非 vacuous 之檢驗【待定】。換手事件之來源若亦可被受攻陷節點竄改，此規則之強度即受限，於 4.8.7 討論。注入瞬移之偵測須同時改動多個來源之上報，檢驗的是**規則之行為**，不代表單一受攻陷節點可發動之攻擊（4.8.4）。此對應攻擊表 type C（謊報位置/瞬移）。

**（移除流量守恆）** 早期版本的 H_i 含「跨小區流量守恆 Σ ΔU_j ≈ 0」。因吞吐量缺 PRB 硬約束（3.3.5），此守恆在 RLC 資料上無法穩健成立，故自 H_i 移除；H_i 聚焦成員轉移（消失 + 瞬移）兩維度。

#### 3.3.4 \(C) C_i：場域 UE 基數守恆驗證

C_i 驗證「量測是否仍描述同一封閉裝置母體」。依 Lamport（1977）提出、Alpern & Schneider（1985）形式化之分類，此為 safety property，其違反可由單一窗即刻觀察，故為布林斷言而非連續分數：

```
N_total(t) = | ∪_all-cells { IMSI ∈ RRC 連線名單 }(t) |    （全場域相異 UE 總數，含 LTE 錨點）
conserved(t) := ( N_total(t) = N_known )                   （D-50PH：N_known = 50；D-S12：N_known = 12）
C_i violated ⟺ N_total(t) ≠ N_known
```

名單之定義：以各 DU 報表時點之 RRC 連線名單為主（(A)），以「窗內有流量之 UE」（(B)，ΔnTx > 0）為對照，兩者皆報（`phase2_percell_spec_v0.md` §9.1）。N_known 為場域事實（已登記裝置數），不是由資料估計之量。

**（布林斷言，非容忍帶）** 採嚴格相等而非 [N_lo, N_hi] 容忍帶：N = 50 時 5% 帶之下界為 47.5，將容忍缺漏 2 個 UE（N_total = 48、49 仍在帶內），使少量 UE 之虛減無法被偵測，故不設容忍帶；若需吸收重連瞬態，改採多窗持續條件（連續 L_C = 2 窗 N_total ≠ N_known 才升級 rejected）。

**（虛減偵測的條件性）** C_i 對單一 O-DU 虛減的偵測是條件性的：其前提為被刪除之 UE 未同窗出現於其他節點之名單。MC 架構下 UE 同時連線於 LTE 錨點與一個 mmWave gNB；若錨點之名單亦列出該 UE，則單一 mmWave DU 自其名單刪除 UE 不改變全域聯集，C_i 即無法察覺（此時須 H_i-D1 等其他證據補）。名單 (A) 下此情形之實際範圍於 D-50PH 上檢查【待定】（4.6.5）。此與守恆式串謀盲點共同構成 C_i「必要非充分」的能力邊界。
