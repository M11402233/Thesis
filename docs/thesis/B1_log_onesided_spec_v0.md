# B1：對數殘差＋單邊檢定（指導教授 2026-11-18 審查意見 B1／B2 之 P0 第一項）規格 v0

**狀態**：先寫規格、後執行；不改主結果、不改凍結值（τ_S = 4、MIN_NEIGHBOR = 2、W_HIST = 10 等）。來源：`docs/thesis/advisor_review_20261118_crosscheck.md`。

## 問題
S_i 空間參照殘差 |d − peer 中位數| / s 之 s 為「各 cell 延遲**水準**之 1.4826·MAD」（C-2），不是殘差尺度；τ·s／median 之中位數 = 0.785（已量），故報低約 21% 以下才可能觸發、報高需 ≈1.8 倍；且殘差右尾重（z p95 = 5.4、p99 = 11.9；左尾至 −3.5）。

## 變體（同一資料、同一注入，只換殘差與尺度）
| 變體 | 殘差 | 尺度（訓練 seed 之乾淨殘差，LOSO） | 檢定 |
|---|---|---|---|
| V0 | d − med(peers) | 現行 C-2（延遲水準） | 雙邊 \|z\|>τ |
| V1 | d − med(peers) | 1.4826·MAD(線性殘差) | 雙邊 |
| V2 | log d − med(log peers) | 1.4826·MAD(對數殘差) | 雙邊 |
| V3 | 同 V2 | 同 V2 | **單邊（報低）**：−r/s > τ |
V1 隔離「尺度定義」之效果；V2 加「對數」；V3 加「單邊」。殘差不另做中心化（與 E9 同）。

## 設定（事前固定）
- τ = 4（凍結值，**不調**）；另報「訓練 seed 匹配誤報」版本：在訓練 seed 之乾淨資料上，把 V1–V3 之門檻定為使其訓練誤報等於 V0 之訓練誤報，再套用到受測 seed（門檻只由訓練 seed 決定）。
- 資料：D-30、`ZT_DELAY_SOURCE=reconstructed`（區間延遲）、LOSO、(seed, cell) 樣本、注入起點 = 序列中點、攻擊窗 = 後半，與 `run_E9_operating_regime.py` 相同。
- 攻擊：階躍 ×{0.5,0.6,0.7,0.8,0.9}（報低）與 ×{1.2,1.3,1.4,1.5}（報高，E9 原有）；漂移：報高 r ∈ {0.005, 0.01, 0.02, 0.04}（E9 原式、無上限）；報低 factor = max(0.5, 1 − r·t)（**有下限 0.5**，教授 B2：漂移須有上限）。
- 指標：每窗偵測率（輔助）；**首次偵測之累積偏差**（|o/d − 1|）與**首次偵測延遲**（窗）、未偵測比例（右設限）——B2 主指標；乾淨誤報（後半）。
- 內建檢查：V0 之乾淨誤報、漂移 0.005／0.01／0.02、階躍 1.2–1.5 須重現 `data/results/d30_delay_reconstructed/E9_operating_regime.json` 之空間參照數字（逐位或 1e-9 內）；不符即停、不調。
- 統計：seed 為單位報平均與 per-seed 範圍（不以窗為單位給信賴區間）。

## 不做／限制
- 不改 `zt_kpm_xapp.py`、不重算融合；RQ3 三欄拆分（S_i／D1／C_i）為後續步驟（需 `run_RQ3_decision_replay.py`）。
- 僅為區間語意（reconstructed）；cell 歸屬仍沿用主檔（最後一筆 PDU 所在 cell），結論須附此限制。
- 乾淨誤報若仍遠高於 1%，如實報告，不為了好看調 τ（匹配誤報版本只看偵測率比較）。
