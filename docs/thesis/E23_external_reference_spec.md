## 3. 威脅模型之新增假設

- 參照量測產生於 DU 之 KPM 組裝點以外（CU-UP 與 UE 端；或營運方之主動探測），攻擊者（被攻陷之 DU）無法改寫。**這是新假設**；CU-UP 或 UE 被攻陷時不成立。
- 抽查：每窗每個 UE 以機率 q 獨立被抽中；攻擊者不知道當窗抽中哪些 UE（依 R2，現行攻擊者對全部 UE 同乘，故抽查對其等同全查之子樣本）。

## 4. 兩種參照

- **Ref-P（實測，D-30 既有）**：R6 之逐 UE PDCP 延遲 p。以訓練 seed（LOSO，其餘 7 seed）對 mmWave 之 (UE, 窗) 擬合 log x = α + β·log p（x = KPM 之 RLC 延遲），殘差 e = log x − (α + β·log p)。對照 **Ref-0**（β = 0，只有截距；無參照資訊之基準）。
- **Ref-O（假設性探測）**：參照 = 真值 x × exp(ε)，ε ~ N(0, σ²)，σ ∈ {0.02, 0.05, 0.10, 0.20}；e = log x_報告 − log 參照。**不是可實現之證據**，只給「若存在精度 σ 之逐 UE 量測」之上界；驗證層級須標「假設性」。
- 節點統計量 m(j, w) = 被抽中且有參照之 UE 之 e 平均；無被抽中之 UE ⇒ 該 (節點, 窗) 無 E_i 證據（S1 中計為未標記，並報涵蓋率）。門檻 θ = 訓練 seed 上 \|m\| 之 0.95 分位（凍結；目標乾淨誤報 0.05，與 S_i 乾淨誤報 0.046 同量級）。E_i 標記 ⇔ \|m\| ≥ θ。
- 攻擊 ×a 使節點全部 UE 之 e 加 log a（精確），故 m′ = m + log a。

## 5. 階段

- **S0（只讀乾淨資料；Ref-P 是否夠緊）**：q = 1。報 β、R²、Spearman、殘差 1.4826·MAD、θ 及其換算倍數 exp(±θ)；測試 seed 之乾淨誤報 FA；DET(a) for a ∈ {0.892, 0.822, 0.8, 0.6}；Ref-0 同報。
- **S1（固定攻擊者之抽查）**：q ∈ {0.1, 0.25, 0.5, 1.0} × {Ref-P, Ref-O 四個 σ}；攻擊 ×0.6、×0.8、漂移 0.01、×0.892、×0.822（R1、R3）。報：涵蓋率、E_i 乾淨誤報、E_i 對竄改 (節點, 窗) 之偵測率；以及准入層級之 FB_strict／MF_strict 於四種組合：V0、V0＋E_i、V1（B-off）、V1＋E_i（「＋E_i」＝ E_i 標記者不准入）。
- **S2（學習型攻擊者；新機器；本版不實作）**：攻擊者動作擴至逐 UE（可只改部分 UE）、觀測含 E_i 結果；判準比照 E21 §8.9。**S1 通過不代表可採用**（E21-S4 之教訓）；S2 另寫規格並另行取得同意。

## 6. 判定（事先寫定）

- **S0：Ref-P 可行** ⇔ 測試 seed 合併之 FA ≤ 0.10 且 DET(0.892) ≥ 0.80。**不可行** ⇔ DET(0.892) < 0.50 或 FA > 0.20。其餘不確定。另報 Ref-P 相對 Ref-0 之 DET 差（PDCP 是否帶來資訊）。
- **S1：** 對每個 (參照, q)：**有效** ⇔ V1＋E_i 之 FB_strict ≤ 0.10 且對 ×0.892、×0.8 之 MF_strict 皆 ≤ 0.20。報最小有效之 q（每種參照）。皆不有效則如實寫。
- 不依結果改 θ 之分位、q 或 σ 之格點。

## 8. 事先揭露之限制

1. Ref-O 為假設；Ref-P 為不同物理量，於 MC 架構下 PDCP 位於 LTE 錨點（CellId 1）。
2. S0／S1 只有固定、全 UE 同乘之攻擊者。抽查之弱點（只改部分 UE、把偏離量縮到 θ 以下）屬 S2。
3. Ref-P 之擬合為跨 seed 合併之單一線性式；E23-pre 所見之持續性節點差異可能同樣出現在 e。
4. 新增可信量測源之假設，須於威脅模型章節明寫。
5. R8：CU-UP 報表之值與 trace 檔有 1.9 % 列不同（seed 4200），本實驗用 trace 檔；二者關係未查明前，正文不得寫「即 CU-UP 之 E2 報表值」。

### 11.3 判讀

1. **實測路線不通**：D-30 內 DU 以外之逐 UE 延遲（PDCP）無法約束 KPM。依 Q6，E23 之外部參照**不進入 S2**，改列未來工作；可寫之結論為「需要對每個 UE、每一窗、精度約 5 % 以內之獨立量測，抽查不足」——此為假設性上界（Ref-O），不是已驗證之機制。
2. **事後觀察（非判定依據；Ref-0 原為對照組）**：Ref-0＝「節點內 UE 之 log 延遲平均，對凍結之全域常數」，乾淨誤報 0.050 下對 ×0.8 偵測 0.870（單窗 S_i 於 ×0.8 之違反率為 3.7 %，E19 §13.3）；與 B-off 合用（即上表 Ref-P 列，其資訊等同 Ref-0）對固定攻擊者 FB 0.056、MF ×0.8 0.143。**不得據此主張**，理由：(a) 事後發現；(b) 參照為凍結之全域基線而非同時態 peer，共模變化與非穩態下之行為未評估（E9c、4.7 之自我參照盲點即此類）；(c) ×0.892 僅 0.369，學習型攻擊者可把偏離量縮至此區間——與 E21-S3 → S4「對固定攻擊者有效、對學習型不保持」同型；(d) 增益來自 log 域或來自全域參照尚未分離。
