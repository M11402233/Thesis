## 3. 設計草案

**3.1 攻擊者動作（每窗）**：`[Δa, m_type, m_k, m_val]`
- Δa：同 R1（延遲倍數）。
- m_type ∈ {無、A1 刪除、A2 替換、A3 宣稱 anchor、A4 宣稱 peer}；m_k ∈ {1, 2, 3}。
- 選哪些 UE：依延遲排序之決定性規則（刪除／替換時選自身延遲**最高**之 k 個；宣稱時選候選中延遲**最低**之 k 個）——讓成員動作有壓低平均之效果（R8）。
- m_val（替換／宣稱之 UE 所報之值）：∈ {原值, 節點平均, 節點最小值}。
- 動作空間：PPO 之 MultiDiscrete＋連續混合不便，建議全部離散化（Δa ∈ {−1, 0, +1}·DELTA）。

**3.2 環境修改**：`Episode.begin` 於成員關係被改動之 episode 改為線上重算 C_i／D2／D1／D3／D4（R3）。**檢查 E27-0**：m_type 恆為「無」時，與現行 `Episode` 逐位相同（重現 E19／E21-S4 之 V0 數字）。

**3.3 偵測端（固定，A-BR 對其訓練）**：F0 = 規則版（V0）；F1 = V0＋D3；F2 = V0＋D3＋D4。不訓練 DRL 偵測端（E19 已顯示只能更嚴之 DRL 無優勢）。

**3.4 攻擊者**：每個偵測端 × {O-full, O-outcome} × 8 fold 訓練 A-BR；對照：延遲型 A-BR（E21-S4 之 ABR[V0]）、腳本 A1–A4。

**3.5 指標**：誘導率（C_strict）、MF_strict、MF_restrict、TPR_rej、攻擊者每窗效用；成員動作之使用率（各 m_type 之比例）；誠實節點之連帶排除（E26 之口徑）。

## 4. 判定（事先寫定；確認後凍結）

- **H-a（規則版有缺口）**：F0 下，成員型 A-BR 之誘導率高於延遲型 A-BR（R9 之 0.464）之 fold ≥ 7／8。
- **H-b（D3＋D4 關閉成員動作）**：F2 下，成員型 A-BR 之 (i) 成員動作使用率 ≤ 1 %，且 (ii) 誘導率不高於延遲型 A-BR 於同一偵測端之值（fold ≥ 7／8）。
- 兩者分開報；不成立即如實寫，不調參數。

## 5. 事先揭露之限制

1. F2 之結果依構造高度可預期（任何成員改動當窗即 rejected，C_R = 1.0）；其價值在確認「無殘餘路徑」，不是新偵測力。
2. 繼承 E25 之假設（CU-CP 可信、D-30 無換手）。D-30H 收齊後可另做含換手之版本。
3. 選 UE 之規則為決定性（依延遲排序），非逐 UE 之自由選擇；自由選擇之動作空間過大，列為未評估。
4. A-BR 為近似最佳回應，不是可利用性之上界（同 E19）。
5. 新機器目前有 Stage 3 之 ns-3 在跑；訓練排程須避開或等其結束（約 11/15）。
