## 2. 攻擊

- **A1_delete**（R6）：虛減。
- **A5_inflate**（本規格新增）：節點 j 於 [t0, t0+L) 每窗加入 k 個假 ID（9001…），其 delay 取該窗 j 之平均（不改變 j 之平均延遲）⇒ N = 30 + k。j 當窗不在報表時不注入。
- 兩者皆使 C_i 違反；攻擊者之目的設為「使誠實節點被排除」。

## 3. 量測（攻擊區間 [t0, t0+L) 內、節點 c ≠ j 之「誠實 (節點, 窗)」）

- 乾淨回放下之准入率（strict、restrict_annotated）與攻擊下之准入率；**連帶排除 = 兩者之差**。另報判定轉移（→ low-trust、→ rejected）之筆數，與「每一筆竄改 (節點, 窗) 連帶排除之誠實 (節點, 窗) 數」。
- 變體：
  - **V-field（規則版）**：現行判定。
  - **V-cand**：C_i 違反且 `candidate_cells` 非空時，C_i 規則只套用於候選 cell；其餘節點之判定＝自 M 移除 `R1_CI_*` 後依嚴重度序重選（R5）。候選為空時同 V-field。
  - **V-D4**：C_i 違反且當窗有節點之 D4 violated 時，C_i 規則只套用於 D4 violated 之節點；其餘同上。無 D4 violated 之節點時同 V-field（fail-closed）。
- 攻擊節點 j 於三種變體下之 MF（strict、restrict）——歸因不得放過 j。
- 攻擊區間外（含區間後 POST = 10 窗）誠實節點判定與乾淨回放之差異筆數（不繼承之確認）。

**判讀**
1. **連帶排除之代價（規則版）**：攻擊者只要讓 C_i 違反，攻擊區間內**全部**誠實節點於 strict 下准入率由 0.496 降為 0，restrict 下由 0.989 降為 0.134（僅第一窗之 `R1_CI_PENDING` 仍准入）。每一筆竄改之 (節點, 窗) 連帶排除 4.8–21 筆誠實 (節點, 窗)。此為阻斷服務型之放大，攻擊者自己也被排除（j 之 MF_strict 0）。
2. **歸因可消除連帶排除**：灌水（A5）以既有之 `candidate_cells` 或 D4 皆可歸因，連帶排除為 0。虛減（A1）無候選 cell，只有 D4b 能歸因；且須涵蓋「攻擊節點把報表刪到空而沉默」之情形（V-D4s，事後新增）——v1 之 V-D4 於此退回場域層級，仍有 0.114–0.657 之連帶排除。
3. V-D4s 下誠實節點另有 3 筆改判 rejected（來源非 C_i；j 之報表改變影響其他證據），攻擊區間外為 0。
4. 歸因變體只限縮 C_i 之套用範圍，j 於 restrict 下之第一窗仍准入（0.102–0.130）；若同時啟用 E25 之 `R1_D4_VETO`，j 於第 0 窗即 rejected（E25 §7）。
5. 限制同 §5；V-D4s 為看過 v1 結果後新增，繼承 E25 之假設（CU-CP 可信、D-30 無換手、無流量之已連線 UE 會誤觸 D4b）。主結果與 `fuse()` 不變。
